# Nocturna Schematic Documentation

This folder contains component schematic references and supporting drawings for the Nocturna wildlife-monitoring platform. These documents support electrical integration planning and review of the camera and positioning hardware.

## Folder Contents

| File or Folder | Description |
|---|---|
| `Oak D pro W schematic.PDF` | Schematic reference for the OAK-D Pro W camera hardware. |
| `GPS/` | Schematic and dimensional reference documents for the TEL0157 Gravity Quectel L76K GNSS positioning module. |

## Camera Documentation

The OAK-D Pro W schematic provides a reference for reviewing the camera hardware and its electrical interfaces during integration with Nocturna’s onboard computing system.

## GPS Documentation

The `GPS/` folder contains two reference documents:

- **Schematics:** Electrical schematic for the TEL0157 Gravity Quectel L76K GNSS positioning module.
- **Dimensions:** Mechanical dimensions for component placement and mounting coordination.

## Design Status

The current folder contains component reference documents. A complete Nocturna system wiring diagram is not yet included.

Future system schematics should identify power connections, communication interfaces, connector pin assignments, and connections between the robot platform and the added equipment.

## Attribution

Component reference documents must retain their original titles and attribution. Their inclusion does not imply that the Nocturna team designed the underlying commercial hardware.

Team-created or modified schematics should identify their contributors, revision date, and any changes made to third-party designs.
