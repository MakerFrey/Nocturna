# Changelog

All notable changes made to the Nocturna repository will be recorded in this document with descriptions and dates posted for each change made and signed off by the contributor making the change.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project __does not__ adhere to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Changelog Guidelines

1.  The most recent changes, with the date of the change, are listed first.
2.  Every change made should have a corresponding CHANGELOG.md entry.
3.  Changes made must be linked within your entry.
4.  Same types of changes are to listed as a group.
5.  Date format: **YYYY-MM-DD** 
6.  The linked changelog version to a corresponding entry number must ascend in value.
  ```Text
    Example:
    [0.1.0] - YYYY-MM-DD (Most recent)

    [0.0.9] - YYYY-MM-DD
    
    ...

    [0.0.2] - YYYY-MM-DD 

    [0.0.1] - 2026-11-04 (Oldest)
  ```
  
### Types of Changes

- `Added` for brand new features
- `Changes` for changes made to existing documentation or fucntions
- `Deprecated`  for soon-to-be removed features or documentation with justification
- `Removed` for removed documentation or features
- `Fixed` for function bug fixes or documentation correcitions
- `Security` for just in case someone needs to make a critical security fix 
- `[YANKED]` are for changes that had to removed due to major faultiness or security risks
- `[Unreleased]` section for tracking upcoming changes you plan on contributing
